၁။ Firebase Web Config ထည့်ပါ

Firebase Console → Project settings ⚙️ → General → Your apps → Web app → SDK setup and configuration → Config မှ အောက်ကတန်ဖိုးများကို ကူးထည့်ပါ။ API key ကို ဒီ chat ထဲ မပို့ပါနှင့်။

Config ကို ဒီ browser ရဲ့ local storage ထဲ သိမ်းထားပါတယ်။ တခြားအသုံးပြုသူများကလည်း သူတို့ browser မှာ config ကို တစ်ကြိမ် ထည့်ရပါမယ်။ Firebase web config က secret key မဟုတ်ပါ; service-account private key များကို မထည့်ပါနှင့်။
